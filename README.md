# 八家公司上市前股权融资统一口径成果

状态：`FINAL_APPROVED`  
统一口径版本：`v1.0`

## 一、本次任务内容

上周Week 6已经分别完成八家公司的上市前融资提取和横向比较。本次任务是在上周成果基础上，对八家公司进行统一口径整理，而不是重新从头分析八份招股说明书。

本次主要完成以下工作：

1. 对八家公司现有成果进行字段映射和横向检查；
2. 统一融资轮次、增资、股权转让和融资金额的统计规则；
3. 统一法律投资主体、PE/VC主体和投资体系的区分；
4. 对异常事项返回招股书原文进行定点复核；
5. 对原结果、统一结果和修改原因进行对照；
6. 按统一口径重新计算八家公司核心指标；
7. 将最终结果整理为Excel、CSV、JSON、口径配置和人工决定记录。

本次任务没有覆盖或改写招股书原始事实层，主要修改发生在统一字段、统计口径和横向比较结果层。

## 二、与上周Week 6成果的对比

上周Week 6的主要成果是分别完成八家公司的融资信息提取，并形成初步横向比较报告。由于各家公司在提取和试跑过程中存在不同的披露方式，部分指标虽然单家公司内可以使用，但公司之间的统计口径还没有完全统一。

本次任务主要对以下问题进行了修正：

| 对比项目 | 上周Week 6结果 | 本次统一后结果 |
|---|---|---|
| 八家公司融资轮次 | 至少17轮 | 至少18轮 |
| 云汉芯城融资轮次 | 6轮 | 7轮 |
| 云汉芯城2009年事项 | 未纳入融资轮次 | 复合事件中的增资部分计1轮，股权转让不另计轮次 |
| 三协电机 | 报告中有2轮，但工程底表无法完整回溯 | 补入2022年和2023年两轮定向发行 |
| 友升股份金浦基金 | PE/VC主体识别存在主体和体系层级问题 | 2个PE/VC法律主体，归入1个投资体系 |
| 赛分科技2021年4月 | 增资和股权转让并列描述 | 分拆为1次增资和1次股权转让，融资轮次只计增资 |
| 融资金额 | 未形成八家公司统一金额指标 | 形成可核验公司融资金额下限173,663.59万元 |
| 股权转让金额 | 未形成统一汇总口径 | 形成可核验转让对价下限17,480.9080万元 |
| PE/VC主体 | 各公司口径不完全统一 | 确认PE/VC法律主体记录16个 |
| 投资体系 | 可能与法律主体混用 | 与法律主体分开，暂不汇总八家公司体系总数 |

除上述修改外，上周Week 6对八家公司融资模式和公司类型的总体判断没有发生实质变化。本次工作的重点是统一统计口径、补齐工程底表和提高横向可比性。

## 三、最终结果

统一口径后，八家公司形成以下核心结果：

- 直接股权融资合计至少18轮；
- 云汉芯城7轮；
- 可核验公司融资金额下限173,663.59万元；
- 可核验老股转让对价下限17,480.9080万元；
- 确认PE/VC法律主体记录16个；
- PE/VC投资体系总数暂不生成。

其中，融资金额和股权转让对价均为当前招股书披露范围内的可核验下限，不代表八家公司完整历史总额。

## 五、文件说明

- `data/八家公司统一口径核心指标_最终验收.xlsx`：最终人工查看和验收文件；
- `data/八家公司统一口径公司指标.csv`：公司级横向指标；
- `data/八家公司统一口径核心指标.json`：机器可读的最终指标；
- `config/unified_caliber_v1_0.json`：统一口径规则；
- `audit/final_decisions_consolidated.json`：重点异常和最终人工决定；
- `scripts/verify_submission.py`：提交文件和核心指标校验脚本；
- `manifest.json`：文件清单、大小和哈希；
- `CHECKSUMS.sha256`：文件完整性校验值。

PDF、DOCX、本周汇报文档以及各步骤中间过程文件不放入本GitHub目录，单独保存在本地归档中。
